# 低调侧边栏

[English](README.md)

打开 DeepSeek Harness 时收起左侧栏。
仍可用原生按钮打开，切换会话不会再次收起。

左右侧栏都使用默认键位时，插件会通过 DSH 的快捷键设置交换它们。
已有自定义键位或原生未绑定的平台不受影响。交换后仍可在设置中编辑，停用插件不会撤销已保存的交换。
若要恢复原生键位，先停用插件，在「键盘快捷键」中清除左侧栏的键位，再依次恢复右侧栏、左侧栏的默认键位。

需要 DeepSeek Harness 0.2.2-rc.5 或更新版本。在外观 Atlas 中启用「低调侧边栏」。
也可在源码目录运行 `pnpm install` 后，从「插件 → 添加插件」单独安装。
同一 profile 请选择一种方式。
