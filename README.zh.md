# 低调侧边栏

[English](README.md)

打开 DeepSeek Harness 时收起左侧栏。
仍可用原生按钮打开，切换会话不会再次收起。

需要 DeepSeek Harness 0.2.2-rc.5 或更新版本。
在外观 Atlas 中「低调侧边栏」默认关闭，可按需单独启用。
也可在源码目录运行 `pnpm install` 后，从「插件 → 添加插件」单独安装。
同一 profile 请选择一种方式。

[项目文档](docs/README.md)
